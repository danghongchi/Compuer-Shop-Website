# Products E-commerce Website

## 📌 Giới thiệu
Website thương mại điện tử bán PC, máy tính và linh kiện máy tính.  
Người dùng có thể duyệt sản phẩm, tìm kiếm, thêm vào giỏ hàng, đặt hàng và thanh toán trực tuyến.  
Admin có thể quản lý sản phẩm, danh mục, thương hiệu, người dùng, đơn hàng và nhiều chức năng khác.  

## 🚀 Tính năng chính
- Đăng ký, đăng nhập, phân quyền (Admin/Khách hàng)  
- Tìm kiếm và lọc sản phẩm theo danh mục, thương hiệu  
- Giỏ hàng & thanh toán  
- Quản lý người dùng, đơn hàng, sản phẩm, danh mục, thương hiệu  
- Thống kê cơ bản và xuất dữ liệu (Excel, PDF, CSV)  

## 🛠️ Công nghệ sử dụng
- **Front-end:** HTML, CSS, Bootstrap, JavaScript/jQuery  
- **Back-end:** ASP.NET MVC, ASP.NET Identity, Entity Framework (ORM)  
- **Database:** SQL Server  

## 📷 Một số giao diện
- Trang chủ, đăng nhập, đăng ký  
- Trang giỏ hàng, checkout  
- Quản lý sản phẩm, danh mục, thương hiệu  
- Quản lý người dùng, đơn hàng, vai trò (Roles)  

## 📈 Hướng phát triển
- Nâng cao giao diện người dùng (UI/UX)  
- Tăng cường tính năng bảo mật  
- Tích hợp thanh toán trực tuyến thực tế  
- Tối ưu hiệu suất và mở rộng hệ thống
